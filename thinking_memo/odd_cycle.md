## 2026.8.27

グラフに含まれる奇数長の閉路を求める関数の実装。
無向と有向でやれることが異なる。今回は無向グラフ版だけに集中した。

#### 戻り値の型について

少なくとも三つの選択肢がある。

1. 奇閉路の頂点列
1. 奇閉路の辺の番号の列
1. 奇閉路の辺 (の実体) の列

ここでは 3 を採用した。1 はそもそも情報が足りていない (辺の番号にアクセスするのに余分なコストがかかる。重みつきの場合は辺のコストも分からない)。2 は辺へのアクセスは O(1) でできるが、無向グラフを扱っている関係上、列挙される辺の向きが揃わないのが不便なため。

#### アルゴリズムについて

少なくとも三つの選択肢がある。

1. DFS
1. BFS
1. 頂点倍加し、元のグラフの辺 u-v に対して 2 本の辺 (u,0)-(v,1) と (u,1)-(v,0) を張る。このグラフの連結成分を求め、(u,0)-(u,1) パスが存在するかどうかを見ればよい。

ここでは 1 を採用した。2 の方針でやる場合、根から有向木を作るように探索するので、向きが揃った閉路を返すためには半分くらいの辺の向きを反転する必要があり、この操作をグラフアルゴリズム上にあんまり出したくない感じがした。3 は有向グラフ版のアルゴリズムと揃っていてきれいだが、実装量が多く定数倍も大きそうなので避けた。

DFS の方針は有向グラフについては正しくない。反例：
```
2 <- 1 -> 5
|    ^    |
|    |    |
v    |    |
3 -> 4 <---
```
このグラフで 1 -> 2 が先に探索されると、1 -> 5 -> 4 -> 1 が見つからない。
