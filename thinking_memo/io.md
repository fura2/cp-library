## 2026.5.31

output 関数がローカル環境では行ごとに flush するように変更した。
multi testcase の問題でテストケースを手入力して試すときに、テストケースごとに結果が表示されないのが不便だったため。

## 2026.6.14

5.31 の変更はリアクティブ問題で不慮の事故が起きそうということに気づいたので、多少の速度を犠牲にしてジャッジ環境でも毎行 flush する方針に変更した。

## 2026.6.25

やはり速さを優先して 5.31 の仕様に戻した。
また、input 関数はこれまで
```cpp
int n = input();
```
と戻り値で型を指定できる書き方にしていたが、これはやや不自然な実装を強いられ、また Grid などの自作クラスに拡張しにくかったため、
```cpp
auto n = input<int>();
```
とテンプレート引数を明示して auto で受ける形に変更した。
書き味の悪さはエディタのコードスニペット機能でカバーする。

## 2026.7.29

`pair<mint, mint>` みたいなのを output しようとすると、末尾改行を含む output 関数をクラスごとにオーバーロードするこれまでの方法だとうまくいかなかった。
Output 構造体を作って、末尾改行を含まない `Output<T>::write` を実装する仕様に変更することで解決した。
入力側の `Input<T>::read` を実装する仕様ときれいに揃ったのでとても嬉しい。

## 2026.9.14

生配列用の `Output<T[N]>::write` を追加した。
これは `output("Alice")` のような文字列リテラルに対してもマッチしてしまうので、
```cpp
inline void output(const char* s) { output<const char*>(s); }
```
を追加して、文字列リテラルについての挙動を保つようにした。
